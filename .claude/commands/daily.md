# Daily 자동 생성

오늘 날짜 기준으로 daily 작업 폴더와 파일을 생성한다.

## 실행 조건

- 프로젝트 루트: 이 파일 기준 `../../` (bdacs 폴더)
- 오늘 날짜를 `date +%Y-%m-%d` 로 구한다
- 템플릿 경로: `template/todo.md`, `template/prompt.md`

## 실행 절차

### 1단계: 날짜 및 경로 계산

- 오늘 날짜: `{yyyy-MM-dd}` (예: 2026-03-25)
- 월 폴더: `workspace/1_daily/{yyyy-MM}/` (예: workspace/1_daily/2026-03/)
- 일 폴더: `workspace/1_daily/{yyyy-MM}/{yyyy-MM-dd}/` (예: workspace/1_daily/2026-03/2026-03-25/)

### 2단계: 이전 daily 찾기

- `workspace/1_daily/` 아래 모든 날짜 폴더를 탐색하여, 오늘보다 이전인 **가장 최근 날짜 폴더**를 찾는다.
- 해당 폴더의 `todo.md`를 읽는다. 없으면 이월 없이 빈 템플릿을 사용한다.

### 3단계: 이월 데이터 추출

이전 todo.md에서 다음을 추출한다:

**공지사항 이월:**
- `# 🔴 공지사항` 섹션의 모든 항목을 그대로 가져온다.

**미완료 항목 이월:**
- 이전 todo.md의 모든 섹션에서 `- [ ]`(체크 안 된 항목)을 수집한다.
- `- [x]`(완료된 항목)는 제외한다.
- 수집한 미완료 항목을 오늘 todo.md의 `# 👊 이어서 할일` 섹션에 넣는다.

### 4단계: 파일 생성

**폴더가 없는 경우** — 폴더를 생성하고 아래 파일을 모두 만든다.

**폴더가 이미 있는 경우** — 각 파일을 확인한다:
- 파일이 없으면 새로 생성한다.
- 파일이 이미 있으면 아래 내용 보강 규칙에 따라 수정한다.

#### todo.md 생성 규칙

```md
# 🔴 공지사항
{이전 todo.md에서 이월한 공지사항, 없으면 빈 줄}

# 👊 이어서 할일
{이전 todo.md에서 이월한 미완료 항목들, 없으면 - [ ]}

# ✅ 오늘 할일
- [ ]
```

#### todo.md 내용 보강 규칙 (이미 파일이 있을 때)

- `# 🔴 공지사항` 섹션: 이전 todo에서 가져온 공지 중 현재 파일에 없는 항목만 추가한다.
- `# 👊 이어서 할일` 섹션: 이전 todo에서 가져온 미완료 항목 중 현재 파일에 없는 항목만 추가한다.
- `# ✅ 오늘 할일` 섹션: 건드리지 않는다.

#### prompt.md 생성 규칙

- `template/prompt.md`를 복사한다.
- `{yyyy-MM-dd}`를 오늘 날짜로 치환한다.
- 이미 파일이 있으면 건드리지 않는다 (대화 기록이므로 덮어쓰면 안 됨).

### 5단계: 결과 보고

완료 후 다음을 출력한다:
- 생성된 폴더 경로
- 생성/수정된 파일 목록
- 이월된 공지사항 수
- 이월된 미완료 항목 수
- 이미 존재하여 건너뛴 파일

출력 예시:
```
📅 2026-03-25 daily 생성 완료

📁 workspace/1_daily/2026-03/2026-03-25/
  ✅ todo.md 생성 (공지 2건, 미완료 3건 이월)
  ✅ prompt.md 생성
```
