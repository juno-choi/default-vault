# Weekly 회고 자동 생성

해당 주차의 daily 데이터를 수집하여 주간 회고 파일을 생성한다.

## 실행 조건

- 프로젝트 루트: 이 파일 기준 `../../` (bdacs 폴더)
- 오늘 날짜를 `date +%Y-%m-%d` 로 구한다
- 템플릿 경로: `template/review.md`

## 주차 계산 규칙

- 월요일 시작, 단순 7일 단위
- W01 = 1/1 ~ 1/7, W02 = 1/8 ~ 1/14, ...
- 공식: `W = ceil(해당 연도의 날짜 순번 / 7)`
  - 예: 1월 8일 = 연도 8일차 → ceil(8/7) = W02
  - 예: 3월 25일 = 연도 84일차 → ceil(84/7) = W12
- 해당 주차의 날짜 범위도 함께 계산한다:
  - W01 시작일 = 1월 1일, 종료일 = 1월 7일
  - W12 시작일 = 3월 22일, 종료일 = 3월 28일

## 실행 절차

### 1단계: 이전 주차 누락 확인

현재 주차를 계산한 뒤, `workspace/2_weekly/{yyyy}/` 폴더를 확인한다.

**W01부터 현재 주차-1까지 빠진 주차가 있는지 확인한다.**

빠진 주차가 있으면 아래 인터뷰를 진행한다:

```
📋 누락된 주간 회고가 있습니다.

빠진 주차: W03, W05, W08
현재 주차: W12

누락된 주간 회고를 먼저 생성할까요?
1. 네, 누락분부터 순서대로 생성합니다
2. 아니오, 이번 주차만 생성합니다
3. 특정 주차만 선택합니다 (예: W05, W08)
```

- 1번 선택 시: 누락된 주차를 오래된 순서부터 차례로 생성한 뒤, 현재 주차를 생성한다.
- 2번 선택 시: 현재 주차만 바로 생성한다.
- 3번 선택 시: 사용자가 지정한 주차만 생성한 뒤, 현재 주차를 생성한다.

각 주차 생성은 아래 2단계~5단계를 동일하게 따른다.

### 2단계: daily 데이터 수집

해당 주차의 날짜 범위에 해당하는 daily 폴더를 탐색한다.

경로 패턴: `workspace/1_daily/{yyyy-MM}/{yyyy-MM-dd}/`

**todo.md에서 수집:**
- `- [x]` 완료된 항목 전부 수집 (날짜 정보 포함)
- `- [ ]` 미완료 항목도 수집 (날짜 정보 포함)

**prompt.md에서 수집:**
- 전체 대화 내용 수집 (🔴 사용자 질문, 🟢 AI 답변 쌍)

해당 주차에 daily 데이터가 하나도 없으면 사용자에게 알린다:
```
⚠️ W12 (3/22 ~ 3/28) 기간의 daily 데이터가 없습니다.
빈 템플릿으로 생성할까요, 아니면 건너뛸까요?
```

### 3단계: 주제별 자동 분류 및 요약

수집한 데이터를 **주제별로 분류하고 요약**한다.

**완료 업무 분류 규칙:**
- 수집한 완료 항목(`- [x]`)을 내용 기반으로 주제를 추론한다.
- 주제 예시: 프로젝트명, 기술 키워드, 업무 카테고리 등
- 동일 주제의 항목은 하나의 그룹으로 묶고, 핵심 내용을 2~3줄로 요약한다.
- 미완료 항목(`- [ ]`)은 별도로 "이월된 항목"으로 정리한다.

**AI 대화 분류 규칙:**
- 수집한 prompt.md 대화를 주제별로 분류한다.
- 주제는 대화 내용에서 추론한다 (예: crypto, Spring Boot, 인프라 등).
- 각 주제별로 핵심 질문과 답변 요약을 작성한다.
- 단순 인사나 짧은 확인 대화는 제외한다.

### 4단계: review 파일 생성

경로: `workspace/2_weekly/{yyyy}/W{nn}_review.md`

#### 신규 생성 시

```md
# 🔴 한주동안 진행한 일

## {주제1}
- 요약 내용
- 요약 내용

## {주제2}
- 요약 내용

### 이월된 항목
- [ ] 미완료 항목1
- [ ] 미완료 항목2

# 🔴 한주동안 ai와 대화한 내용 정리

## {주제1}
- 핵심 질문과 답변 요약

## {주제2}
- 핵심 질문과 답변 요약
```

#### 내용 보강 시 (이미 파일이 있을 때)

- 기존 파일을 읽는다.
- 기존에 없는 주제가 있으면 새 섹션을 추가한다.
- 기존 주제에 새로운 내용이 있으면 해당 섹션에 항목을 추가한다.
- 기존 내용은 삭제하지 않는다.
- 이월된 항목 중 이미 완료 처리된 것은 제거한다.

### 5단계: 결과 보고

완료 후 다음을 출력한다:

```
📅 W12 (2026-03-22 ~ 2026-03-28) 주간 회고 생성 완료

📁 workspace/2_weekly/2026/W12_review.md
  ✅ 완료 업무: 8건 (3개 주제로 분류)
  ✅ AI 대화: 5건 (2개 주제로 분류)
  ⏳ 이월 항목: 2건
  📊 수집된 daily: 5일분 (3/22 ~ 3/26)
```
